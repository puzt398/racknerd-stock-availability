## 蹲补货的六个动作

补货没有时间表。物理节点装满就显示 sold out，补货等于新节点上线或老节点扩容，官方通常不预告具体时间。能做的只有把动作做对。

1. **从特价页进，不要走常规 VPS 入口。** 常规 VPS 起价 $2.24/月，配置和特价档接近，价格贵一倍多。
2. **看 Location 下拉，不要看别人整理的库存表。** 那是唯一实时且准确的信息源。
3. **盯官方公告。** 补货和新套餐会发在官方博客与客户面板的 Announcements 板块，公告里通常写明补了哪个机房、多少节点。
4. **大促前把账号和付款方式准备好。** 黑五、新年、周年庆这几个节点，往年几乎都有动作，热门档几小时内清空是常态。这只是历年规律，不是官方承诺今年一定有。
5. **别只盯一个机房。** 圣何塞没货，达拉斯、芝加哥、西雅图的配置完全一样，只是位置不同。
6. **看到就下单。** 特价套餐的库存是按机房算的，犹豫一晚可能就没了。

机房在下单时锁定，买完想换只能新开一台再迁数据。所以下单前先测延迟，别买了再后悔。
